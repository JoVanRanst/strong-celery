# Project strong-celery
This project is a automations handler/scheduler built on the Django webframework

## Getting started
To get the setup running on CPanel:
1. Create a python application in CPanel 
2. Link that python app to the repo location
3. Within the python venv you get from CPanel, run the CPanelInit.sh file.
4. Setup the (sub)domain in CPanel
5. Setup the sql database in CPanel
